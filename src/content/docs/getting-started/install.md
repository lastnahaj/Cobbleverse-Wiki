Cobbleverse runs on **Minecraft 1.21.1 with Fabric**. Use the pack supplied through the community's official download channel, then add the multiplayer address:

```text
cv.infinitegamingservers.com
```

## Modrinth setup

1. Install the Modrinth App and sign in with the Microsoft account that owns Minecraft Java Edition.
2. Search for **Cobbleverse** under Modpacks and install the matching release.
3. Open the instance settings and allocate at least **4096 MB (4 GB)** of memory. More may help on systems with enough available RAM.
4. Launch the pack once before adding optional client mods.
5. Open Multiplayer, add the address above, and join.

## CurseForge setup

1. Install the CurseForge launcher and choose Minecraft Java Edition.
2. Search for **Cobbleverse**, install the current pack, and keep its bundled mods, datapacks, and resource packs together.
3. Allocate at least **4 GB** of memory in the profile or launcher settings.
4. Launch, add the server address, and connect.

## Before changing the pack

Test the untouched pack first. Extra mods, datapacks, shaders, or resource packs can cause crashes and missing models. Back up single-player worlds before updating or changing files.

The Lumy Hub installation articles cover the public base pack. The hosted Cobbleverse server may update on a different schedule, so the server's Discord announcement wins when versions differ.

## Server owners

The base pack has one-click or guided hosting routes for Apex and Nitrado. The published guidance requires at least 4 GB of RAM, recommends a backup before every update, and warns operators to preserve worlds and custom files when replacing pack folders. These hosting steps are for private server operators, not players connecting to `cv.infinitegamingservers.com`.
