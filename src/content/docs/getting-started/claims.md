Cobbleverse uses **Flan** for land protection and adds Cobblemon Flan Integration so Pokémon activity can respect claim permissions. Use the in-game claim interface for exact limits and controls.

## Before you claim

Choose land with enough room for your build, check for nearby protected chunks, and leave reasonable space for neighbors.

## Claim tool

The claim tool is a **golden hoe**. Select claim corners with the tool and use Flan's interface to review or manage the resulting area. Server permissions can change which controls appear.

## Chunk Anchors

Cobbleverse also uses a Chunk Anchor concept for single-chunk protection. Acquisition and per-rank limits are server settings.

## Pokémon actions in claims

The installed integration can control:

- Pokémon spawning
- catching
- starting battles
- sending Pokémon out
- riding
- Display Case interaction

Upstream defaults are not treated as Cobbleverse policy. Claim-owner bypasses and global protections can be configured independently, so check the live claim menu before relying on a particular action.

## Troubleshooting checklist

- Confirm you are using the intended claim tool.
- Check whether the chunk overlaps an existing protected area.
- Keep the exact location handy when asking staff for help.
- Use the official Discord for current support guidance.
