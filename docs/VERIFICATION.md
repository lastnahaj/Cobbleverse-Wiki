# Server verification register

Installation reports identify Journey, Wonder, Bazaar, Smart Trainers, Bloom, Colosseum, EEssentials, CobbleWorkers, Cobblemon Extras, Flan integration, SkiesGUIs, and Universal Daily Rewards. Installation does not verify their current configuration.

## Unpublished configuration

- Command permissions, home limits, teleport cooldowns, and workstation access.
- Market fees, auction durations, listing limits, prices, taxes, and reward values.
- Trainer teams, battle formats, Tower rewards, and server-specific level rules.
- Claim limits, bypass permissions, and action restrictions.
- Client compatibility and optional voice setup.
- NeoPlushies keys, codex, wishlists, recycling, shards, and seasonal acquisition.
- Regional Pokédex thresholds and future-region unlock requirements.

Candidate stack entries with no repository evidence remain `unknown` and `playerFacing: false` in the systems register. Confirm installation from a current mod manifest before changing their status. Do not publish infrastructure or administrative controls in player navigation.

## Evidence standard

Record a version and date, source URL or reviewed configuration, the player-visible behavior, and any local differences. A base-pack guide can be useful without being server-verified. Do not infer a live configuration from an upstream feature list.

The imported reference index contains search summaries. Only the Pokémon, move, and ability feeds preserve full structured records; item, shop, guide, and trainer indexes must not be described as complete walkthroughs.
